# 🏥 Hospital Emergency Room Dashboard

An interactive **Microsoft Excel Dashboard** designed to analyze and monitor Emergency Room (ER) performance using dynamic charts, Pivot Tables, KPI cards, and slicers.

## 📌 Project Overview

The **Hospital Emergency Room Dashboard** provides a comprehensive view of hospital operations by visualizing important healthcare metrics. It helps users monitor patient flow, waiting time, admission status, satisfaction score, gender distribution, age groups, and department referrals through an interactive Excel dashboard.

---

## 🎯 Objectives

- 📊 Monitor Emergency Room performance
- 👨‍⚕️ Analyze patient admissions
- ⏱️ Track average waiting time
- ⭐ Measure patient satisfaction
- 👥 Study gender and age group distribution
- 🏥 Analyze department referrals
- 📅 Filter data by Month and Year

## 📊 Dashboard Metrics

| Metric | Description |
|---------|-------------|
| 👥 Total Patients | Total number of patients |
| ⏳ Average Wait Time | Average waiting time of patients |
| ⭐ Patient Satisfaction Score | Overall satisfaction rating |
| 🏥 Admission Status | Admitted vs Not Admitted |
| 🚹🚺 Gender Analysis | Male & Female distribution |
| 👶👴 Age Group Analysis | Patient distribution by age |
| 🩺 Department Referral | Department-wise referrals |
| ⏰ Attendance Status | On-Time vs Delay |
