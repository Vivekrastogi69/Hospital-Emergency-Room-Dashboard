# Hospital Emergency Room Dashboard

## Overview

This project is an interactive Hospital Emergency Room Dashboard created in Microsoft Excel.

The dashboard helps analyze patient data such as:

- Number of Patients
- Average Wait Time
- Patient Satisfaction Score
- Admission Status
- Patient Age Groups
- Department Referral
- Gender Analysis
- Attendance Status
